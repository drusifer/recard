# The Jev player library

Generated by `bobp make jev-library-doc` from the library's own entries
(`tools/jevLibrary.mjs`) - do not edit by hand; a test fails when this
file is stale.

A game's turn file (`games/<game>/turn.yaml`, US-129/D154) is an XState
v5 statechart whose guards, actions and actors are the names below. A
name the library does not have is refused when the file loads.

**Events** the seat sends: `TABLE` (every look at the table, carrying
`changed`, `quietFor`, `heard`), `STEP` (take one step), `QUIT`
(asked to leave).

**Tags** the author writes: `move` (it is this bot's move here) and
`safe` (a bot asked to leave may leave from here; at least one must be
reachable). `busy` is added by the interpreter to every state that
invokes an actor. A `type: final` state ends the run.

**Parameters** go in `params` (guards, actions) or `with` (actors);
the names in backticks in each line below are the ones it reads.

## Generic

### guards

- `verdict` - the last judgment or table answer was `is` (yes | no | unsure)
- `table_changed` - the board or the talk moved since the last look (the bot's own lines excluded)
- `quiet_table` - the board changed and nobody has spoken for `ms` since
- `counted` - context `field` has reached `at_least` (a number, or another context field)
- `played` - the step just taken was a move of kind `move` (e.g. pass, cast)

### actions

- `count` - add one to context `field`
- `track` - keep what the last move changed (its `tracks`) in context
- `reset` - set context fields to the values given in `to`
- `say` - say `text` at the table

### actors

- `judge` - ask Jev `question` (a Noul) about the table and talk; output verdict yes | no | unsure
- `ask_table` - say ONE yes/no question (`say`) and wait for a person's answer; output verdict yes | no | unsure
- `play` - one step in `phase`: Jev picks from the legal options (`question`), the rules check it, and the move is made and said

## rtg

### guards

- `heard_attack` - RtG: someone just announced an attack ("attacking with ...")

### actions

- `hear_attackers` - RtG: remember who was just announced as attacking

## gin

### guards

- `gin_phase` - Gin: the table says it is phase `is` for me (draw | discard | wait | hand-over)

### actions

- `note_hand_over` - Gin: log that a hand ended, and how many of the run's hands are done

### actors

- `gin_look` - Gin: read the table - whose move it is, and which hand
- `gin_step` - Gin: one decision (draw or discard) by the seated strategy, acted and said
